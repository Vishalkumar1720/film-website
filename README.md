# Anjali — The Birthday Monograph & Cinematic Film

An editorial scroll-driven digital dedication and cinematic motion picture experience celebrating Anjali on September 23.

---

## ✨ Features

- **The Editorial Monograph**: High-fashion serif typography, smooth Lenis momentum scrolling, interactive stardust particles, dynamic botanical motifs, parallax portrait showcase, and gold foil interactive moments.
- **The Cinematic Film Edition** (`/film/`): 35mm film simulation, vintage grain texture, widescreen cinema HUD with live timecode, smooth camera zoom-ins, dynamic scene cuts, and emotional typography.
- **High Performance & Optimization**: Automated WebP and responsive asset compression with zero-delay loading.
- **Responsive Architecture**: Pixel-perfect typography and fluid layouts across mobile, tablet, and ultra-wide displays.

## 🛠️ Tech Stack

- **Vite 5** (Fast ES module bundler & multi-page build)
- **Vanilla JavaScript (ESNext)**
- **Lenis Smooth Scroll**
- **GSAP (GreenSock Animation Platform)**
- **Canvas Confetti**
- **Custom HTML5 Canvas Particle Engine**

## 💻 Local Development

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Vishalkumar1720/film-website.git
   cd film-website
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start local development server**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```

---

## 🚢 Deployment

Automated via **GitHub Actions** (`.github/workflows/deploy.yml`).
Every push to the `main` branch automatically builds and publishes the production site to GitHub Pages.
